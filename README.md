# 🛒 Flutter E-Commerce UI

A simple and clean **Flutter E-Commerce UI project** featuring a Home Page and Cart Page. This project was created to practice Flutter UI development, product layouts, navigation, and basic shopping cart functionality.

## ✨ Features

* 🏠 Home Page
* 🛒 Cart Page
* 🛍️ Product Cards
* ➕ Add Products to Cart
* 📱 Responsive UI
* 🧭 Page Navigation
* 🎨 Clean & Simple Design

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material Design**

## 📱 Screens

The project currently includes:

### 🏠 Home Page

Displays products in a clean and user-friendly shopping interface.

### 🛒 Cart Page

Displays the products added to the cart with basic cart functionality.
